# FlowMath Uroflow Practice

Post-lecture practice for *Interpreting Uroflowmetry Curves With Mathematics* (Stephen Shei-Dei Yang, MD, PhD; Tze-Chen Chao, MD; Li-Yi Lim, MD, MBBS, FRCS).
Participants classify 60 uroflowmetry curves (Bell, Tower, Plateau, Interrupted, Staccato, Unclassifiable)
and compare their readings with the expert reading and with other participants.

Live site: https://uroflowmath-lab.github.io
