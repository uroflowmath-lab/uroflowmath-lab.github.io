# FlowMath Uroflow Practice

Post-lecture practice for *Interpreting Uroflowmetry Curves With Mathematics* (Stephen S. Yang, MD, PhD).
Participants classify 50 uroflowmetry curves (Bell, Tower, Plateau, Interrupted, Staccato, Unclassifiable)
and compare their readings with the expert reading and with other participants.

Live site: https://uroflowmath-lab.github.io
